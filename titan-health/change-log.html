Deployment Rules

  1. Never deploy directly to Prod — always go through Full (UAT) first
  2. Test in your Dev sandbox before promoting to Full
  3. Log every change in this file before deploying to Full
  4. Run all Apex tests in Full after deploying: sf apex run test --target-org titan-full --result-format human
  5. Al's admin changes in prod should be retrieved and added to source: sf project retrieve start --metadata "CustomField:Case.FieldName" --target-org titan-prod
  6. Conflicts: If two developers modify the same component, the second deployer must retrieve the latest from Full before deploying

Deploy Commands

# Deploy from your dev to Full (UAT)
sf project deploy start --source-dir metadata/force-app/main --target-org titan-full
sf project deploy start --source-dir metadata/force-app/phase2 --target-org titan-full

# Deploy from source to Prod (after UAT approval)
sf project deploy start --source-dir metadata/force-app/main --target-org titan-prod
sf project deploy start --source-dir metadata/force-app/phase2 --target-org titan-prod

# Retrieve Al's prod changes into source
sf project retrieve start --metadata "CustomField:Case.NewField__c" --target-org titan-prod --output-dir retrieve-tmp

# Run all tests
sf apex run test --target-org titan-full --result-format human
